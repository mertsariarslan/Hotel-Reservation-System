# Hotel Reservation System 🏨

This is a console-based hotel reservation system developed during my first year as a Computer Engineering student at Ankara Medipol University. The project was built to practice foundational Java programming concepts, including 2D arrays, loops, conditionals, and method implementations.

## 📌 Features
- 🏨 **Dynamic Hotel Layout:** Generates a hotel grid based on user-defined floor and room counts.
- 🛏️ **Booking & Checkout:** Updates and manages the availability status of specific rooms.
- 🔍 **Smart Search:** Locates the first available room within a specified floor range.
- 👨‍👩‍👧 **Group Booking:** Automatically detects three consecutive empty rooms on the same floor.
- 📊 **Occupancy Tracking:** Reports the total number of occupied rooms in real-time.

## 🛠️ Technologies Used
- **Language:** Java
- **Core Concepts:** 2D Arrays, Console I/O, Procedural Programming
- **Libraries:** Standard Java libraries
